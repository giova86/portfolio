ConvertToMD - Web Application

A fully local web application that converts PDF, DOCX, DOC, XLSX, and XLS files into Markdown.

Python FastAPI React HTML Ollama LLM

Overview

ConvertToMD is a fully local web application that converts documents — PDF, DOCX, DOC, XLSX, and XLS — into clean Markdown, without sending any file to an external service.

A React and HTML front end handles uploads and previews, while a Python/FastAPI backend performs the conversion, using a locally-run LLM through Ollama to help with the document-to-Markdown transformation.
