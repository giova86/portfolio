Face Tracking

A Python computer-vision tool that turns any webcam into an intelligent, auto-framing virtual camera. Built on MediaPipe's FaceMesh, it tracks the speaker's face in real time, smoothly recentres and zooms the frame, and streams the result to any app that accepts a virtual camera — no extra hardware needed.

Python PyVirtualCam OpenCV Mediapipe
GitHub

Overview

Face Tracking turns a static webcam feed into an auto-framing virtual camera for video calls, online classes, and streaming. Rather than a fixed frame, it continuously detects the speaker's face and recentres and crops the video so the subject stays framed as they move — without a PTZ camera or any manual repositioning.

Under the hood, MediaPipe's FaceMesh model runs on every frame captured through OpenCV, using a stable point on the nose bridge as the tracking anchor. The raw position is smoothed twice — first with a weighted moving average that favours the most recent frames, then with an exponential filter — before the frame is cropped around it and resized back to the output resolution with OpenCV's cubic interpolation. The result is pushed to a system virtual camera device via pyvirtualcam, so any application that accepts a webcam source — OBS, Zoom, Google Meet, Discord, Teams — can use it directly as a video source.

If the face briefly leaves the frame or detection drops for less than a second, the last known velocity is used to extrapolate its position, keeping the crop moving fluidly instead of snapping back to centre. The script also probes several FaceMesh configurations at startup and auto-detects the available camera devices, so it degrades gracefully across different setups. A companion script, app_multi.py, extends the same approach to two people at once: it keeps both speakers in a single shared frame while they're close together, then automatically switches to a synchronised split-screen view — with hysteresis to avoid flicker — once they move far enough apart.

Key features

  • Automatic face tracking that keeps the subject stable and centred, anchored on a nose-bridge landmark from MediaPipe's FaceMesh.
  • Dynamic zoom: crops the frame to a configurable "active area", removing unnecessary empty space for a more professional look.
  • Two-stage smoothing — a weighted moving average plus exponential filtering — to prevent jerky camera motion.
  • Motion prediction: if the face is momentarily lost, its position is extrapolated from the last known velocity to keep the frame moving fluidly.
  • Highly configurable via command-line arguments — zoom, smoothing window, recency weighting, resolution, FPS, and camera device ID.
  • Headless mode for running on a server or in the background without preview windows.
  • Broad compatibility: streams through pyvirtualcam, so any app that accepts a webcam source — OBS, Zoom, Google Meet, Discord, Teams — can use it out of the box.
  • Multi-face variant (app_multi.py) that automatically switches between a unified two-person frame and a synchronised split-screen view as speakers move apart.

Tech stack

Python

Core language for the whole pipeline; an argparse-driven CLI exposes zoom, smoothing, resolution, FPS, and camera-device settings so the tool can be tuned per use case without touching code.

OpenCV

Captures frames from the physical webcam, handles colour-space conversion, crops and resizes the tracked region with cubic interpolation, and draws the debug overlays shown in the preview windows.

Mediapipe

Runs the FaceMesh model that detects facial landmarks on every frame; the app uses the nose-bridge point as a stable tracking anchor and falls back through progressively looser detection/tracking confidence configs if the strictest one fails to load.

PyVirtualCam

Streams the cropped, recentred frame to a system-level virtual camera device, so any conferencing or streaming app can pick it up as a normal webcam source.
