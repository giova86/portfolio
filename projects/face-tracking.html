Face Tracking

A Python-based application designed to enhance virtual meetings by providing real-time face tracking capabilities. The tool leverages computer vision to identify and follow faces during conference calls.

Python Sklearn OpenCV Mediapipe
GitHub

Overview

Face Tracking is a Python application built to make virtual meetings smoother by automatically following the speaker's face in real time. Instead of a static webcam frame, the tool keeps the presenter centred as they move.

It relies on computer vision techniques to detect and track faces frame by frame during conference calls, using Mediapipe and OpenCV for face and landmark detection, with Sklearn supporting the underlying data processing.
