Magic Calculator - Mobile Application

Magical calculator app that always returns the same result, no matter what you enter — a mind-bending trick tool!

Dart Flutter

Overview

Magic Calculator looks and behaves like a fully working dark-mode calculator — basic arithmetic, percentages, sign changes, an animated splash screen — until its hidden "secret mode" is switched on. From that point, pressing = stops evaluating the expression the player typed and instead always returns a pre-configured number, no matter what was entered. It's a magic-trick prop disguised as a utility app: to a bystander it's just a calculator, but the performer can silently prime it to "predict" any number they choose in advance.

Secret mode is toggled by long-pressing the small dotted icon next to the "0" button; the icon itself swaps between two glyphs (⋱/⋰) so the performer has a discreet visual confirmation of which mode is active without giving it away to onlookers. The secret result is configurable from a hidden dialog reachable by long-pressing the menu icon in the top-left corner, and it's persisted across app restarts with shared_preferences.

Outside of the trick, the calculator is a genuinely complete single-screen Flutter app: it parses and evaluates real arithmetic expressions with the math_expressions package, keeps a running expression/result display that reflows its font size to the screen width, and formats very large or very small results in scientific notation so they never overflow the display.

Key features

  • Hidden "secret mode": long-pressing the ⋱ button toggles a mode where the = button ignores the typed expression entirely and returns a fixed, pre-set number instead of the real result — the core of the magic trick.
  • Configurable secret number: long-pressing the menu icon opens a dialog to set the number the calculator "predicts" in secret mode, saved to disk with shared_preferences so it survives app restarts.
  • Real arithmetic engine when not in secret mode: expressions are parsed and evaluated with the math_expressions package, supporting addition, subtraction, multiplication, division, percentages (%) and sign toggling (+/-).
  • Smart number formatting: results are capped at a fixed character budget, switching to scientific notation for very large or very small values and trimming decimal places so long numbers never overflow the display.
  • Responsive, fully proportional layout: button size, spacing and every font size are computed from the screen width with clamp(), so the same layout adapts cleanly from small phones to tablets.
  • Animated dark-themed splash screen: a circular progress ring, icon fade-in and color transition are choreographed with a single AnimationController and staggered Interval curves before handing off to the calculator screen with a cross-fade transition.
  • Tactile button feedback: number and operator buttons lighten and lose their drop shadow on onTapDown, giving a pressed-in feel that reverts on release or cancel.
  • Standard calculator conveniences: AC to clear everything, a context-sensitive backspace that appears while typing, and consecutive-operator replacement (typing a second operator swaps the last one instead of appending it).
  • Locked portrait orientation with immersive, edge-to-edge system UI, including a native platform channel that detects Android's navigation mode (gesture vs. button bar) to pick the correct system UI overlay.

Tech stack

Dart

Implements the calculator state machine as a single StatefulWidget: expression building, operator handling, the secret-mode switch, number formatting for scientific notation, and the splash-screen animation timeline, all with plain dart:async and no external state-management package.

Flutter

Renders the responsive button grid and display with Row/Column/ FittedBox, drives the splash-screen ring, fade and color transitions with AnimationController/Tween/CurvedAnimation, and handles button press feedback and long-press gestures with custom GestureDetector-based button widgets. A native MethodChannel queries the Android navigation-bar mode at startup to choose the correct SystemUiMode.

math_expressions

Parses the typed arithmetic string into an expression tree and evaluates it in real mode whenever secret mode is off, powering the calculator's actual math.

shared_preferences

Persists the configurable secret number to local device storage, so the value set through the hidden dialog survives across app restarts.
