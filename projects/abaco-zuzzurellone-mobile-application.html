Abaco Zuzzurellone - Mobile Application

Mobile version of the famous game "Abaco-Zuzzurellone"

Dart Flutter

Overview

Abaco Zuzzurellone is a mobile adaptation of the classic Italian party game of the same name — a word hunt played entirely by alphabetical order. The app hides a secret Italian word and asks you to find it by narrowing an alphabetical interval that starts, as the name suggests, between abaco and zuzzurellone.

Every guess is compared lexicographically against the hidden word: if it comes before, it becomes the new lower bound; if it comes after, it becomes the new upper bound. The playable range shrinks with each attempt until only the secret word is left — a binary search the player runs with their own vocabulary, with the score being how few attempts it took.

It is built with Flutter and Dart as a single cross-platform codebase for Android and iOS. All the game logic, the ~106,000-word Italian dictionary and the artwork ship inside the bundle, so the game is fully playable offline with no backend and no network calls.

How a round works

  • Startup — a loading screen shows the logo while the dictionary is read from the asset bundle and cached in memory, then hands over to the main menu.
  • Menu — "Nuova Partita" always available, plus "Riprendi Partita" when a saved game is detected; an in-app rules dialog explains the bound mechanic before the first round.
  • Guessing — the game screen keeps the current interval on screen (DA in cyan, A in magenta) above an auto-focused text field, so submitting guess after guess never requires leaving the keyboard.
  • Feedback — a rejected guess is explained inline in the input hint (invalid word, already tried, outside the current bounds) and reverts after two seconds; an accepted one confirms "Intervallo ristretto!" and redraws the tightened range.
  • Ending — matching the word opens the victory screen with the answer and the attempt count; giving up through the "Arrenditi" menu action opens the defeat screen, which reveals the word all the same. Both offer an instant rematch or a return to the menu.

Key features

  • ~106,000-word Italian dictionary bundled as a plain text asset, loaded once into a static list and reused for both picking the secret word and validating every guess.
  • Strict guess validation — a guess must be a real dictionary word, must not have been played before in the same round, and must fall strictly inside the current interval. Rejected guesses cost nothing: the attempt counter only advances once all checks pass.
  • Automatic save and resume — the secret word, both bounds, the attempt count and the list of previous guesses are persisted after every valid move, so closing the app mid-round loses nothing. The save is cleared on victory or surrender.
  • Guarded destructive actions — starting a new game over an active one, or surrendering, both require confirmation through a dialog before progress is discarded.
  • Neon dark theme — a cyan/magenta palette over a near-black surface, Poppins typography, per-screen full-bleed backgrounds with gradient scrims, and glowing bordered cards and gradient buttons for the interactive elements.
  • Screen-size aware layout — spacing and type scale across small, medium and large phones, long words shrink to fit their card instead of overflowing, and the scrollable intrinsic-height layout keeps everything reachable when the keyboard is up.
  • Native Android navigation handling — the app detects whether the device uses gesture or three-button navigation and picks the matching immersive system-UI mode, so the full-screen artwork never fights the system bars.
  • Portrait-locked and fully offline — orientation is pinned at startup and the whole game runs from bundled assets and on-device storage.

Tech stack

Dart

Holds the whole game model in a single GameLogic class: random word selection, lexicographic comparison via String.compareTo to move the bounds, guess validation against the dictionary, and the save/load/clear lifecycle. Async APIs are used throughout for asset and storage access.

Flutter

Provides the four screens (loading, menu, game, victory/defeat) as stateful and stateless widgets with a shared dark ThemeData. LayoutBuilder, FittedBox and MediaQuery breakpoints handle responsiveness; rootBundle loads the dictionary and artwork from the asset bundle.

shared_preferences

Persists the round across app restarts — bounds, attempts, secret word and the JSON-encoded list of past guesses — plus the flag the menu reads to decide whether to offer "Riprendi Partita".

google_fonts

Pulls the Poppins family into the app-wide text theme, giving every screen consistent typography without shipping font files manually.

Kotlin platform channel

A small MainActivity exposes a navigation_mode_channel MethodChannel that reads the Android navigation mode from secure settings, with fallbacks to the system resource config and the navigation-bar height. Dart applies the matching system-UI mode and degrades gracefully when the channel is unavailable.
