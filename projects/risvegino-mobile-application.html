RisveGino - Mobile Application

Mobile version of the "RisveGino" manual of Risvegliati VIP Brescia.

Dart Flutter

Overview

RisveGino is the digital field manual for Risvegliati VIP Brescia, an association of volunteer clown doctors ("claun") who run scheduled clown-therapy services in hospitals, care homes and other health and social facilities. Before the app, the operational details each volunteer needed before a service — which structure, on what day, at what time, wearing what protective equipment, who the responsible "angel" was — lived in a paper or PDF manual that was awkward to search and quickly went out of date. RisveGino turns that manual into a searchable, always-up-to-date mobile directory that every clown carries in their pocket.

The home screen lists every partner structure as a card, with free-text search over name and address plus quick filter chips for day of the week and structure type (hospital, RSA, day centre, and so on). Tapping a card opens a detail screen with the service's full operational profile: schedule and time slot, mask requirements, maximum capacity, the responsible angel, beneficiaries, expected operators, preparation notes, service organisation, and any extra remarks — plus a one-tap link that opens the structure's address directly in Google Maps, and a fixed safety notice reminding volunteers of the association's photo and privacy rules.

Behind that simple list is a small sync system: the canonical structures.json is hosted on Dropbox, and the app authenticates against the Dropbox API with a refresh token to pull the latest version, diff it field-by-field against the copy cached on the device, and — the first time it runs, or whenever the user taps the sync button — show a human-readable summary of what actually changed ("new structures added", "opening hours updated for X"), rather than just silently overwriting the data. Firebase Cloud Messaging complements this: a push notification tells volunteers a new bulletin is available, which triggers the same background sync so the local list stays current without anyone needing to reinstall the app or download a new PDF.

The app is built with Flutter and Dart, giving it a single cross-platform codebase for Android and iOS, and is themed with the association's own hand-drawn clown branding (custom "Komica" and "Comic Sans" typefaces, a red/white colour scheme, and a splash screen with the RisveGino logo) so it reads as a natural extension of the paper manual it replaced.

Key features

  • Searchable structure directory — every partner facility is listed as a card with name, type, weekly schedule and mask policy at a glance; free-text search matches on structure name or address.
  • Day and type filters — horizontally scrolling chips let volunteers narrow the list to a specific day of the week or a specific structure type, so they can quickly find "what's on today".
  • Full operational detail sheet — tapping a structure opens its complete profile: schedule and time, capacity, the responsible angel, beneficiaries, number of operators expected, preparation notes, service organisation and any extra information, each shown only when actually present in the data.
  • One-tap navigation — the structure's address is tappable and opens directly in Google Maps via url_launcher, taking volunteers straight from the app to turn-by-turn directions.
  • Cloud-backed data sync with change summary — a manual sync button (and an automatic background check on launch) pulls the latest structures.json from Dropbox, diffs it against the on-device copy, and reports exactly which structures are new or which fields changed, instead of a blind overwrite.
  • Push notifications — Firebase Cloud Messaging keeps every device subscribed to a shared "strutture" topic, so an update to the manual can be broadcast to all volunteers and trigger an automatic re-sync, with a local notification shown even while the app is open.
  • Safety and privacy reminders — the detail screen always surfaces the association's operational rules: who to notify if a volunteer can't attend, how to report attendance, and an explicit, highlighted ban on posting photos from inside a facility on social media.
  • Custom clown-themed UI — a dedicated splash screen, header artwork, and the association's own "Komica" and "Comic Sans" fonts give the app a distinct, playful identity that matches the volunteers' own materials rather than a generic Material look.

Tech stack

Dart

Implements the app's state, data model and business logic: parsing structures.json into typed Structure objects, driving search/filter logic, and computing the field-level diff used to summarise remote updates.

Flutter

Provides the single cross-platform UI for Android and iOS — the structure list, filter chips, sliver-based detail screen with a collapsing header, and the custom clown-themed styling and animations.

Firebase Cloud Messaging

Delivers push notifications to every installed app, broadcasting manual updates to the "strutture" topic and waking a background sync so volunteers see fresh data without manually checking.

flutter_local_notifications

Shows a native notification when a push message arrives while the app is already open in the foreground, on both Android (via a dedicated high-priority channel) and iOS.

Dropbox API

Hosts the canonical structures.json manual. The app authenticates with an OAuth2 refresh token to fetch the latest file, letting the association's data owners update the manual by editing a single shared file rather than shipping a new app release.

url_launcher

Opens a structure's address directly in Google Maps from the detail screen, handing off navigation to the device's native maps app.

path_provider

Locates the app's documents directory so the synced structures.json can be cached on-device and reloaded on subsequent launches without a network round-trip.
