Wanted OP - Mobile Application + API

Mobile app for iPhone/Android to create personalized One Piece wanted posters with images, names, and custom rewards.

Python FastAPI Dart Flutter

Overview

Wanted OP - Mobile Application + API is the mobile counterpart to the One Piece wanted poster generator, built with Flutter and Dart to run natively on both iPhone and Android.

Users can upload a photo, enter a name, and set a custom bounty amount to create their own personalized wanted poster. The app talks to a FastAPI backend written in Python, which handles the poster generation.

Key features

  • Upload a photo from the gallery or take one directly with the camera.
  • Customize the poster with a name and a bounty amount.
  • Real-time preview of the generated poster.
  • Save the finished poster as an image to the device.
  • Intuitive interface inspired by the One Piece wanted-poster aesthetic.

Tech stack

Python

Backend language for the poster-generation service consumed by the app.

FastAPI

Exposes the API that composes the uploaded photo, name, and bounty into the final poster image.

Dart

Application logic: state management and coordinating image picking, preview, and saving.

Flutter

Cross-platform UI for iPhone and Android, including the image picker, live poster preview, and screenshot/save flow.
