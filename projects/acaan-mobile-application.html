ACAAN - Mobile Application

Any Card At Any Number — a card-magic effect brought to your phone.

Dart Flutter

Overview

ACAAN is a performance tool for close-up card magic, built around the classic "Any Card At Any Number" plot. The phone stands in for a real deck: the performer secretly sets a target card, hands the device to a spectator, and whatever they do with the cards, the first one they turn over is the target.

The secret is in the deck graphic itself. The closed deck is divided into an invisible 2×2 grid — one quadrant per suit — and the open deck into an invisible 3×5 grid running from Ace to King. Two taps that read as nothing more than handling the deck are enough to arm the effect, with no menus, no typing and no tells on screen.

Once the deck is spread, all 52 cards become individually draggable and flippable objects. The spectator can shuffle them around the screen, stack them and browse as long as they like: the force is applied on the first flip, by swapping the tapped card's face with the target card and giving its old face to the card that previously held the target — so the deck on screen always remains a legitimate 52-card deck with no duplicates.

It is built with Flutter and Dart as a single cross-platform codebase for Android and iOS, running entirely offline from bundled assets.

How a performance runs

  • Setup — an animated splash screen plays while every theme's deck and card-back images are pre-cached, so no asset ever pops in mid-performance.
  • Choose the suit — one tap on a quadrant of the closed deck. Nothing on screen changes except the deck opening, which reads as a natural handling move.
  • Choose the value — the open deck hides a 3×5 grid; a second tap picks the rank. Depending on the configured exit mode, the deck then leaves the screen on a tap or is dragged away with a downward swipe that doubles as the rank selection.
  • Hand it over — the cards spread into a loose pile, each with a small random offset and tilt. The spectator drags, stacks and browses freely; every touched card lifts, scales and comes to the front of the stack.
  • The reveal — the first flip, single- or double-tap depending on the setting, turns up the target card with a 3D rotation.
  • Reset — one button gathers the cards back to centre, then reshuffles a fresh deck ready for the next spectator.

Key features

  • Invisible selection grids — suit and rank are picked by hit-testing the touch position against the deck image's own geometry (2×2 closed, 3×5 open), so the interface that arms the trick is completely unmarked.
  • Undetectable force — the target face is swapped in on the first flip and traded with the card that already held it, keeping the deck internally consistent if the spectator turns over every remaining card.
  • Two deck-exit modes — tap-to-exit or drag-to-exit, the latter letting the performer pick the rank and slide the deck away in a single continuous gesture. The choice is saved between sessions.
  • 38 card themes — deck, open deck and card back are all driven by a filename suffix declared in a JSON manifest, so a new theme is three images and one entry, with no code changes. Themes are browsed through a scaling carousel and the selection persists across restarts.
  • Tunable handling — flip on single tap (fast) or double tap (safe against accidental reveals), plus a flip-duration slider from 0.5 s to 5 s to match the pace of the routine.
  • Physical card feel — a perspective 3D flip with an overshoot curve, a scale bump through the turn, a lift on drag, and shadows whose opacity, blur and spread track how far the card is "off the table".
  • Built-in bilingual guide — a six-step illustrated walkthrough covering suit, value, spreading, the reveal, reset and settings, available in Italian and English through an in-app language toggle.
  • Performance-safe presentation — portrait lock, immersive full-screen tuned to the device's Android navigation mode, asset re-caching when the app returns from background, and a fallback placeholder behind every image so a missing asset can never break a show.

Tech stack

Dart

Drives the deck state machine (inDeck → deckOpening → open → scrollingOut → gathering), the hit-testing that turns a touch Offset into a suit or rank, the face-swap that applies the force, and the list reordering used as a z-index for card stacking.

Flutter

Renders the splash screen, deck and 52 card widgets. AnimatedPositioned and AnimatedRotation handle the spread and gather; Matrix4 with a perspective entry and rotateY handles the flip; layered AnimationControllers combine the flip, scale and drag-lift effects. GlobalKeys keep each card's animation state alive as the stack is reordered.

JSON theme manifest

A bundled themes.json is parsed at startup into typed CardThemeConfig objects that derive their three asset paths from a suffix, with an optional per-theme card-back override. This is what keeps 38 themes maintainable as data rather than code.

shared_preferences

Persists the performer's setup — the selected card theme and the deck exit mode — so the app reopens configured exactly as it was left.

Kotlin platform channel

A navigation_mode_channel MethodChannel reports whether the Android device uses gesture or three-button navigation, so the app picks the immersive system-UI mode that keeps the deck full-screen without the system bars intruding.
