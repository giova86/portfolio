Cosmos - Web Application

Multi AI Agent

Python Javascript React FastAPI Ollama LM Studio OpenAI LLM

Overview

Cosmos is a multi AI agent web application, built to coordinate several LLM-driven agents behind a single interface.

The backend, written in Python with FastAPI, can talk to models served locally through Ollama and LM Studio as well as through OpenAI, while a React front end provides the user-facing interface.
