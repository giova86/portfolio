Choosen - Mobile Application

Choose a card from the deck and predict it.

Dart Flutter Ntfy

Overview

Choosen is a Flutter app built for a card-based mentalism trick: the spectator freely browses through a shuffled 54-card deck and stops on any card they like — the app never shows the card on screen, but privately notifies the magician which one it was.

The app opens on a blurred Start screen; tapping Start reveals the full pile, rendered card-by-card with a deterministic offset and rotation so it reads as a real, imperfectly squared deck. The spectator drags the top card off in any direction to reveal the next one underneath, as many times as they like. As soon as they leave a card on top for a configurable delay, Choosen posts to the ntfy push-notification API with that card's rank, suit, and face image as an attachment — delivered straight to the magician's own device, with nothing revealed on the spectator's screen.

A triple-tap anywhere on screen opens a hidden Settings panel to configure the ntfy topic and notification delay, and a reset button reshuffles the deck back to the blurred Start screen at any time.

Key features

  • Full 54-card deck (13 ranks × 4 suits + 2 jokers), rendered from individual card face assets rather than a single pre-baked deck image.
  • Free-direction swipe-to-dismiss with a fixed distance threshold, snap-back animation, and a seamless hand-off between the "peeking" card underneath and the newly promoted top card — no visual pop-in.
  • Private, per-card push notifications via the ntfy JSON publish API, including the card's face image as a file attachment.
  • Configurable notification delay (0–300s, with 0 disabling notifications entirely) and ntfy topic, persisted locally with shared_preferences.
  • Hidden triple-tap gesture that reveals a floating Settings panel, animated in from the top.
  • Animated blur/sharp transition between the Start screen and gameplay.
  • Deck-exhaustion handling with a "Ricomincia" (restart) flow that reshuffles and returns to Start.

Tech stack

Dart & Flutter

The whole app — UI, gesture handling, animations, and state — is a single Flutter codebase (SDK ^3.9.2) targeting iOS and Android from one source tree.

Ntfy

Notifications are sent by POSTing directly to the public ntfy JSON API with a compact title (e.g. A♠️, Jolly 🃏) and the card's face image as a file attachment — no backend of its own, just a self-hostable or public ntfy server.

shared_preferences

Persists the magician's ntfy topic and notification delay locally between sessions.

http

Lightweight HTTP client used to publish notification payloads to the ntfy API.
