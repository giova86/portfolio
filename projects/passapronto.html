PassaPronto

A practical solution that monitors real-time availability of passport appointment slots on the Italian State Police website, sending notifications via Telegram or email.

Python Streamlit Docker Telegram Bot API
The project

Overview

PassaPronto is a practical tool built to solve a real annoyance: the scarcity of available appointment slots for passport renewal on the Italian State Police booking website. It continuously checks for newly opened slots on the user's behalf.

When a slot becomes available, PassaPronto sends an immediate notification through Telegram or email, so the user can book it before it disappears. It runs as a Streamlit app packaged with Docker, with the Telegram Bot API handling the alerts.
