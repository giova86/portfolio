Tic Tac Drop - Mobile Application

Advanced tic-tac-toe app where pieces disappear after a few turns, adding a strategic twist to classic gameplay.

Dart Flutter

Overview

Tic Tac Drop takes the familiar 3x3 tic-tac-toe grid and gives it a sliding-window twist: each player can only ever have three marks on the board. Placing a fourth automatically removes that player's oldest mark before the new one lands, so the board is never static — every move quietly weakens an existing line and opens up a square somewhere else.

It's a single-screen Flutter mobile app with two modes: local two-player (pass-and-play on the same device) and a rule-based AI opponent. The whole game — state, board rendering, computer logic, and result dialogs — lives in one StatefulWidget, animated with Flutter's own AnimationController/Tween APIs rather than an external animation package.

The core design problem is the classic tic-tac-toe win check no longer being enough on its own: with marks disappearing, both the player and the AI need to reason not just about "can I make three in a row now" but "which of my pieces is about to vanish, and does that break a line I'm relying on."

Key features

  • Sliding three-piece rule: each player's moves are tracked in a FIFO queue (Queue<int>); placing a fourth mark evicts the oldest one from the board automatically, keeping the game in constant flux instead of filling up and ending in a draw.
  • Two game modes from the home screen: local pass-and-play against a friend, or a single-player match against a built-in AI.
  • Rule-based AI opponent with a priority ladder: it first checks every available move (including the piece it would have to drop) for an immediate win, then checks whether the human's next move would win and blocks it, then falls back to taking the center, then to a random legal move.
  • "About to disappear" indicator: the cell holding the current player's oldest piece blinks (via a looping AnimationController) whenever that player already has three marks on the board, so the next capture is telegraphed instead of being a surprise.
  • Live win highlighting: the three winning cells are picked out in gold once a line of three forms, using the same coordinate list the win-checker scans.
  • Persistent scoreboard for X, O across games within a session, reset together with the board via the "New game" action.
  • Responsive board layout: a LayoutBuilder switches between a stacked portrait layout and a side-by-side landscape layout (board + scoreboard/status panel), sizing the grid off the available width/height rather than fixed constants.
  • In-app rules screen explaining the base rules, objective, game modes, and the piece-eviction strategy twist, reachable from both the home screen and the in-game app bar.

Tech stack

Dart

Implements the game state machine: move validation, the FIFO eviction of each player's oldest piece via dart:collection's Queue, the eight-combination win check shared by both the human and the AI, and the AI's win/block/center/random decision ladder.

Flutter

Renders the board with a GridView.builder over AnimatedContainer / AnimatedDefaultTextStyle cells, drives the blinking "next to be removed" cue and tap feedback with AnimationController/Tween, and adapts the layout between portrait and landscape with LayoutBuilder.
