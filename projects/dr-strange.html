Dr. Strange

Brings the magical world of Dr. Strange to life by allowing users to generate and display real-time, interactive shields similar to those seen in the Dr. Strange movies.

Python Sklearn SVM OpenCV
GitHub

Overview

Dr. Strange is a computer vision project that brings the magical shields from the Marvel films to life, generating real-time interactive shield effects that respond to the user in front of the camera.

It combines OpenCV for real-time video processing with an SVM classifier built with Sklearn to recognise the gestures or hand positions that trigger the shield effect.
