Magic Coin - Mobile Application

Make an object appear from thin air, move it with a tilt, make it vanish with a flick.

Dart Flutter

Overview

Magic Coin is a Flutter app built for a close-up magic trick: an object appears out of thin air on a fullscreen black stage, can be freely dragged around, and vanishes off the edge of the screen when flicked away fast enough. What started as a single coin has grown into a small "trick toolkit" with 18 selectable objects, an accelerometer-driven shake gesture, tilt-based physics, and a hidden "broken glass" screen gag.

The project was built test-first: every gesture and physics rule below is backed by an automated Dart test, with the trickiest logic (multi-touch detection, fling and tilt physics) kept as pure, dependency-free functions so it can be unit-tested without spinning up a widget tree.

Key features

  • 18 selectable objects, not just coins: 2€, 1€, 5€ and USA coins, a Chinese coin, a ring, a keyring, a lighter, a nose, an LED, a die, an AirPod, a BIC cap, a key, a folded card, and both a bitten and a whole Oreo — each with its own artwork and default size.
  • Three ways to make the object appear: a two-finger tap (default), a one-finger tap, or a sharp shake of the phone against your palm, detected from raw accelerometer data (a fast acceleration spike immediately followed by a dead stop, distinguishing a real palm-slap from walking or waving the phone around).
  • Tilt-based physics: once on screen, the object rolls like a ball on a tilted tray — it accelerates while the phone is tilted, decelerates from friction when the phone flattens out, and comes to a hard stop at the screen edges. Dragging with a finger always takes priority and cancels any tilt velocity on release.
  • Physically sensible fling-to-dismiss: releasing the object makes it vanish only if it's moving fast enough and near the edge it's exiting through, so a hard flick from the middle of the screen doesn't send it flying by accident; a slow release instead snaps it back onto the stage.
  • Per-variant, persistent sizing: a slider (50–400px) resizes the current object instantly, in place, and each of the 18 variants remembers its own size independently, restored on the next launch alongside the chosen object, gesture, and every other setting.
  • Hidden settings entry point: the settings button is fully invisible (opacity 0) but still tappable in its original spot, so the "Magic Noir" gold-accented settings sheet — with a horizontally scrollable object picker, size slider, gesture switch, and background/glass toggles — only opens for someone who knows exactly where to tap.
  • Custom background: the black stage can be swapped for a photo picked from the device gallery via image_picker, so the trick can be performed over any backdrop.
  • Secret "broken glass" gag: an optional full-screen "cracked screen" overlay can be set to appear together with the object; it's dismissed with a hidden triple-tap gesture anywhere on the overlay, without disturbing the object underneath.

Tech stack

Dart

All app and physics logic — gesture detectors, fling/tilt geometry, and settings persistence — is plain Dart, kept deliberately free of Flutter widget dependencies so it can be covered by fast, headless unit tests.

Flutter

Renders the fullscreen immersive stage, the draggable object, and the custom "Magic Noir" settings bottom sheet, and ties the pure-logic modules to real touch, sensor, and lifecycle events.

sensors_plus

Streams accelerometer data for two independent features: the shake-to-appear gesture and the continuous tilt readings that drive the on-screen physics.

shared_preferences

Persists every user choice to disk behind a single SettingsRepository wrapper — selected object, appear gesture, each variant's own size, the glass-effect toggle, and the custom background — restored automatically on the next launch.

image_picker

Lets the user pick a photo from the device gallery to replace the black stage with a custom background.
