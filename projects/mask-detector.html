Mask Detector

Real time mask detector. Identify and analysis all faces looking for a covid mask.

Python Mediapipe OpenCV SVM

Overview

Mask Detector is a real-time computer vision tool built during the COVID-19 period to identify whether people in a video feed are wearing a face mask.

Faces are detected and analyzed frame by frame, with each one classified as masked or unmasked, making the tool suitable for quick visual compliance checks.

It combines Mediapipe and OpenCV for face detection and image processing with a Support Vector Machine classifier for the mask/no-mask decision.
