PixelForge - Web Application

A local, offline image processing app: compress, resize or AI-upscale.

Python FastAPI React HTML

Overview

PixelForge is a local, offline image processing application that runs entirely on the user's machine, with no data leaving the device.

It offers a set of image operations — compression, resizing, and AI-based upscaling — through a React and HTML front end backed by a Python/FastAPI service.
