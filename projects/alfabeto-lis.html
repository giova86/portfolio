Alfabeto LIS

A machine learning model that detects the right hand, extracts the main features, and predicts the corresponding sign in Italian Sign Language based on hand shape.

Python Sklearn OpenCV Mediapipe
Live Demo

Overview

Alfabeto LIS is a machine learning application that recognises letters of the Italian Sign Language (LIS) alphabet from hand shape. It detects the user's right hand through the webcam and classifies the sign being made.

The pipeline extracts hand landmarks with Mediapipe, derives the main features from them with OpenCV, and feeds those features into a Sklearn model trained to predict the corresponding letter.
