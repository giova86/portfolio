Pi Book - Mobile Application

Calculator app that finds the position of number sequences within Pi's infinite decimal expansion — fun for math lovers!

Dart Flutter

Overview

Pi Book looks like an ordinary dark-themed calculator, but every number it computes is silently checked against a million digits of π. Whenever the current expression or result exists somewhere in Pi's decimal expansion, the app reveals it: an icon changes color, and a long press on the calculator button reveals exactly where the sequence lives — as if Pi had been printed in a physical book, split into pages, rows and columns.

The idea plays on the fact that Pi is (conjectured to be) a normal number: every finite digit sequence — a birth date, a phone number, today's calculation — should appear in it somewhere. Pi Book turns that curiosity into an interactive party trick hidden inside a fully working calculator.

Key features

  • Full four-function calculator (addition, subtraction, multiplication, division), plus percentage, sign toggle, decimal input and backspace/all-clear — built on top of the math_expressions shunting-yard parser rather than hand-rolled arithmetic.
  • Live Pi-sequence detection: after every keystroke the app strips the sign and decimal point from the current expression or result and searches for it inside a bundled million-digit Pi dataset.
  • Visual "found in Pi" indicator that changes color the instant the current number is located inside the expansion, with no extra tap required.
  • Long-press reveal on the calculator button: press and hold to see the sequence's exact position expressed as a page, row and column — as if π were printed across pages of 48 rows × 60 digits.
  • A single tap toggles a persistent "book view", swapping the fake status bar's clock and battery readout for the Pi page and row/position numbers, so the position stays on screen without holding the button down.
  • A convincing disguise: the top bar mimics a real phone's status icons (Wi-Fi, signal, battery, clock), so the Pi feature stays hidden until you know the long-press gesture.
  • Animated splash screen with a scaling, fading π mark inside a circular progress ring before handing off to the calculator.
  • Dark theme throughout, locked to portrait orientation, with responsive button and font sizing based on screen width so the layout holds up across phone sizes.

Tech stack

Dart

Implements all app logic: expression state management, the Pi-sequence search over the bundled digit string, and the page/row/column math that turns a raw index into a "book" position.

Flutter

Builds the entire UI — custom circular calculator buttons with press animations, the AnimationController-driven splash screen, and gesture handling (tap vs. long-press) on the calculator button that switches between the two Pi-reveal modes.

math_expressions

Dart package used to parse and evaluate calculator expressions via its shunting-yard parser, instead of writing a custom arithmetic evaluator.

Platform channel (Android)

A native MethodChannel queries the device's system navigation mode (gesture vs. button navigation) at startup, so the immersive UI hides the right system bars on each device.
